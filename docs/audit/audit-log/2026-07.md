## 2026-07-18 — `phase-2-differential-fuzzing` (T2 v1) — random-program kernel-vs-Icarus differential fuzzer (`tests/differential_fuzz.rs`, `differential_fuzz_matches_icarus`) run for the first time

First real run (seed 12648432, i=2) found and fixed **BUG-18** (MEDIUM) — `extend()` of a literal (directly or through nested `extend`/`trunc`) emitted an unsized bare Verilog number, which Icarus rejects as "indefinite width" inside a self-determined concatenation operand; the emitter's `Builtin::Extend` now renders a constant-resolved argument as an explicitly-sized `W'd{v}` literal (approach A, emitter-local resolver — `crates/mimz-core/src/emit_verilog/expr.rs`). Same "checker accepts it, emitter/simulator disagree" class as BUG-6/BUG-11/BUG-16/BUG-17. A deeper N=500 pass then surfaced a **separate** divergence (seed 12648451), filed as **BUG-19** (MEDIUM, then OPEN, FIXED 2026-07-19 — see below): our kernel treats `bits[N] - bits[N]` as an (N+1)-bit carry-extended result (lossless `-`, correctly per spec), but Verilog computes it at N bits in a self-determined concat operand, misaligning the concatenation and silently narrowing the result. Deliberately deferred (user decision 2026-07-19) — does not block the default N=20 CI gate, likely belongs alongside BUG-17/A1's broader self-determined-context fix rather than another one-off patch. 886/886 tests at HEAD.
