## BUG-37: `S0220` code collision in the mixed signed/unsigned arithmetic fix

A CI fuzz run (`lex_parse_eval`) crashed on `sum = !a + b` where `a: signed[4]`
— `!a` coerces to `bits[1]`, so `+` mixed an unsigned and a signed operand.
`crates/mimz-sim/src/sim/value/binary.rs`'s `add`/`sub`/`mul` called
`mimz_core::width_rules::lossless_result` and `.expect()`'d success, trusting
the checker to have already rejected mixed-signedness — but the
`lex_parse_eval` fuzz target intentionally evaluates straight off the parser,
bypassing the checker, so the `.expect()` panicked (libFuzzer deadly signal).

The fix that came in for review changed `add`/`sub`/`mul` to return
`Result<Val, Box<Diag>>` and map `RuleError::KindMismatch` to a `Diag` instead
of panicking — correct in shape, but it reused `S0220`, which
`crates/mimz-sim/src/sim/diag.rs`'s `ALL_SIM_CODES` already permanently
assigns to "file defines multiple modules — none picked" (that catalog is
append-only; a code is never reused once assigned).

### Decision: allocate a fresh `S0240` for the mixed-signedness runtime error

- **Context:** reviewing the BUG-37 fix before merge, `S0220` was already
  claimed by a `sim/value/mod.rs` module-selection error, documented in
  `docs/code/13-tooling.md` and asserted by
  `crates/mimz-sim/tests/sim_errors.rs`'s fixture-per-code contract test.
- **Decision:** the mixed signed/unsigned arithmetic error now uses `S0240`
  (next free slot in the `S02xx` expression-evaluation range).
- **Why:** two semantically unrelated diagnostics must never share one code —
  it breaks `mimz explain`, the docs table, and the append-only contract the
  catalog's own header states.
- **Impact:** `crates/mimz-sim/src/sim/value/binary.rs` (`math_rule_err`),
  `crates/mimz-sim/src/sim/diag.rs` (`ALL_SIM_CODES`, now 80 entries),
  `crates/mimz-sim/tests/sim_errors.rs` (new `s0240_...` fixture + contract
  list), `docs/code/13-tooling.md` (code table + range row).

Verified: `cargo test -p mimz-sim` (243✓) and
`cargo clippy -p mimz-sim --all-targets -- -D warnings` clean.
