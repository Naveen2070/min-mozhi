## Release-accuracy audit (v0.1.0..HEAD) + CHANGELOG/RELEASE_NOTES rewrite

Audited all 582 commits since tag `v0.1.0` against `CHANGELOG.md`,
`RELEASE_NOTES.md`, the audit ledgers, and the live tree before tagging
v0.2.0.

**Findings (pre-fix):**

- The "no breaking keyword change" claim was **false**: 13 reserved words
  were activated post-v0.1.0; nine of them (`bundle`, `loop`, `foreach`,
  `return`, `assert`, `cover`, `sim`, `bind`, `speed`) were not previously
  reserved and break v0.1.0 identifiers with `E1101` (verified with the
  built binary).
- The Added section never introduced whole features that landed after
  v0.1.0: combinational `fn`, tagged unions, bundles, packages/namespacing,
  stdlib, `loop`/`sync loop`/`const if`/`default`, new builtins, wide
  > 128-bit constants, CLI commands, LSP hover/def/completion.
- Six commits landed after the `prepare v0.2.0` freeze: `E0420` (clog2
  port-width diagnostic), open bug `BUG-75` (printer depth vs parser
  MAX_DEPTH), lab lessons + test bump.
- Stale counts: bugs claimed 73/69/4 -> actual 74 filed / 67 fixed / 5
  open (+ BUG-10 half-fixed, BUG-12 re-filed); tests 1318 -> **1320**
  (docs_sync-enforced); goldens "88 .v: 71+17" -> **87 .v: 70+17** (the
  88th file is a stray `tests/golden/counter.vcd`); fixtures 120 -> 121.
- Verified correct at freeze: gap ledger's "eight open", 226-file corpus
  sweep, 5000-seed fuzz depth, edition slug/version wiring.

**What was done:**

- Rewrote the `[0.2.0]` CHANGELOG section as compact bullets: added the
  missing language/tooling entries, split breaking changes into two
  explicit bullets (`<<` lossless; keyword activation with rename note),
  added Performance and Security sections, corrected all ledger/test
  counts to HEAD truth, disclosed BUG-10's pending returns-side flattening
  under Known issues.
- Rewrote `RELEASE_NOTES.md` as the compact per-release blurb mirroring
  the corrected changelog (highlights / breaking / correctness / known
  issues / install).
- No code, spec, or test changes - docs only. `E0420` and `BUG-75` were
  already synced into spec/code docs by their landing commits.
