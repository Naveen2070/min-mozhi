the inlined rationale. Corrected per feedback: "dereference" means the

spec above" referring to a citation that no longer exists — removed.

Verified zero `.rs` files reference `.local.md` repo-wide
(`grep -rn '\.local\.md' --include=*.rs`). `cargo build --workspace
--all-features`, `cargo fmt --all -- --check`, and
