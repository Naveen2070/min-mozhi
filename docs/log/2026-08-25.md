## site: switched raw pagefind CLI to astro-pagefind integration, fixed preview search

Root cause found: old `astro build && pagefind --site dist` script ran the
pagefind CLI _after_ `astro build` finished - but `@astrojs/vercel`'s own
`astro:build:done` hook (which copies `dist/` -> `.vercel/output/static`)
already ran as part of that `astro build`. Result: `dist/pagefind` existed
but never made it into the Vercel static output, so `/pagefind/*` 404'd in
`astro preview` and on deploy - search silently empty.

Fix: `astro-pagefind` integration hooks the same `astro:build:done` event,
but Astro fires integration hooks before the adapter's copy step, so the
index is written before Vercel copies static files. Confirmed via build log
ordering and by diffing `.vercel/output/static/pagefind/` (now present,
was missing before).

Changes:

- `site/astro.config.mjs` - added `pagefind()` to `integrations`.
- `site/package.json` - dropped manual `pagefind --site dist` from
  `build`/`build:site`; removed now-redundant `pagefind` devDependency
  (pulled in transitively by `astro-pagefind`); added
  `astro-pagefind@^2.0.1`.
- `Search.astro` untouched - same `/pagefind/pagefind-ui.{css,js}` paths.

**Verification:** `npm run build:site` - pagefind indexed 60 pages, log
confirms hook order (pagefind writes index, then vercel copies static
files). `npm run preview` - curled `/pagefind/pagefind.js` and
`/pagefind/pagefind-ui.js`, both 200.
