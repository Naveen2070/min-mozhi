### Task 3 — BUG-55: recursed BUG-47's signed-`>>` hoist into `if`/`match` branches

Root cause one level deeper than the filed repro: `expr.rs`'s `IfExpr`/`Match`
rendering always hoisted branch shifts with `allow_shift: false` — correct
only when the `if`/`match` itself sits in a context-determined position
(BUG-24), wrong whenever it sits in a self-determined one instead (concat
member, `extend()`'s argument, a `min`/`max`/`abs`/cast/`fn`-call operand,
…), since `eval_ctx` propagates the SAME `expected_width` into every
branch/arm. Fixed by factoring `IfExpr`/`Match` rendering into
`if_expr_subst`/`match_subst` (new `allow_shift` parameter) plus a new
`render_shift_ctx_operand` helper that every one of the ~20 existing
self-determined call sites now renders its child through, instead of
`expr_subst` directly — one mechanism, not a special case bolted onto
`Extend` alone.

New differential `bug_55_signed_shift_right_inside_match_wildcard_arm_matches_icarus`
watched fail first (`git stash` of just the emitter change: kernel says 0,
Icarus says 3 — the exact filed values), then pass restored.
`bug_24_regression_shift_in_if_branch_stays_unhoisted` (the guard this fix
must not break) stays green — its `if` sits at a bare top-level assignment
RHS, a position the new call sites never touch. `self_determined_regression`
55/55; full workspace 1234/1234 (the 2 `wasm_parity` failures are a
pre-existing stale-WASM-build issue, confirmed by reproducing them
identically on unmodified HEAD). `fmt`/`clippy -D warnings` clean.

### Task 5 — BUG-54: `expect`'s guard now fails on an `x`-valued comparison

`emit_test_stmts`'s `Expect` arm (`emit_verilog/testbench.rs`) rendered
`if (!(cond)) FAIL`; under Verilog's 4-state logic `!(x)` is `x`, and `if`
treats `x` as false, so an all-`x` design (never reset, never driven)
silently printed PASS. Changed to `if ((cond) !== 1'b1) FAIL` — case
inequality against `1'b1` is never itself `x`, so it fails correctly on
`x`/`z` as well as a plain `0`.

New unit test `expect_guard_uses_case_inequality_not_plain_negation` pins
the emitted text directly (mimz's own "every reg/mem has a mandatory init
value" design makes a genuine `x` at an `expect` point unreachable from
valid source alone in practice, so this is a text-shape test, not a full
Icarus round-trip) — watched fail against the pre-fix rendering, restored.
Re-verified `tests/icarus.rs`'s `emitted_testbench_reset_deassert_does_not_race_the_dut`
(previously vacuous per BUG-54's own filing) is now actually sensitive to
BUG-51's regression class: reintroducing BUG-51 (`<=` → `=`) now correctly
prints FAIL and fails the test, where before this fix it printed PASS
either way. 14 testbench goldens regenerated (`tests/golden/*_tb.v`) — every
diff is exactly and only the guard-shape change, confirmed by inspection.
Full workspace green (same 2 pre-existing `wasm_parity` failures, nothing
else); `fmt`/`clippy -D warnings` clean.

`bugs.md`: BUG-54 now `(HIGH, FIXED 2026-08-11)`.

### Task 6 — BUG-53: array-instance `decls` keyed off the loop counter, not the folded index

`insert_repeat_instance_output_kinds` (`emit_verilog/module/ports.rs`) keyed
every `repeat`-body instance's `decls` entry as `{inst}__{i}` using the raw
loop counter `i`, diverging from `inst_name`'s own `{inst}__{eval_const(inst.index)}`
render whenever the index isn't the bare loop variable (`s[i + 1]`), and only
scanned `r.items` one level deep, missing instances nested inside another
`repeat` or a `const if`. Same "arm present, data source under-populated"
shape as BUG-48. Fixed by splitting the function into three
(`insert_repeat_instance_output_kinds` /
`insert_repeat_instance_output_kinds_in` /
`insert_array_instance_output_kinds`), keying by the same folded `index`
expression `inst_name` uses and recursing into nested `Repeat`/`ConstIf`/`ForEach`
the way `emit_instances` already does — one shared shape of traversal instead
of two that can drift.

The review's own repros still fail in `mimz sim` (`S0125`/`S0126`) even
though `mimz check` accepts them, so `differential_clocked` couldn't be used
for the new tests; added `emitter_only_clocked_check` instead — bypasses the
kernel and checks the emitted Verilog directly against real Icarus. Three new
tests (`bug_53_offset_array_instance_index_matches_icarus`,
`bug_53_nested_repeat_array_instance_matches_icarus`,
`bug_53_const_if_in_repeat_array_instance_matches_icarus`) watched fail
pre-fix at the exact filed values (Icarus 174, declared 350) via `git stash`
of just the emitter change, pass restored. A fourth test
(`bug_53_control_case_non_zero_base_identity_index_still_hoists`) pins the
review's own control case (non-zero base, identity index) as a regression
guard, using `differential_clocked` since that shape simulates fine. Full
workspace green (same 2 pre-existing `wasm_parity` failures, nothing else —
no golden mismatches, since this touches `decls` population, not emitted
text); `fmt`/`clippy -D warnings` clean.

`bugs.md`: BUG-53 now `(HIGH, FIXED 2026-08-11)`. The check/sim/emit
disagreement table BUG-53 exposed (checker accepts, simulator rejects,
emitter silently miscompiles) is **not** resolved by this fix — tracked as
Task 8, still open.
