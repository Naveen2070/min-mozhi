- Important, fixed: `simplify_muxes` turned a `validate`-clean module
  invalid when a bypassed mux fed a `Shl`'s `b` pin. `validate` sizes a
  `Shl` exactly once `b` is one `Const` cell's `out`, but `lower` sized it
  worst-case (`WidthMismatch expected 6 found 7` on
  `wire amt: bits[2] = if c { 2 } else { 2 }; o = x << amt`). Reachable
  from source; no corpus example has it.
  - Fix: `simplify_once` drops every net a `Shl.b` pin reads from the
    substitution map, the same guard as `const_fold`'s
    `feeds_a_shift_amount`. Cost: that mux's other readers are not
    bypassed either.
  - Test `never_bypasses_a_mux_that_feeds_a_shift_amount`, RED with the
    reviewer's exact error, then GREEN.
- Deferred minors (not fixed):
  - `for_each_read_net_mut` also visits input ports. Harmless, since a mux
    `out` never aliases an input-port net in a `validate`-clean module.
  - R2 can make bypassed bits known where `Executor` reported the whole
    mux value unknown. Recorded in the `docs/audit/gaps.md` mux-simplify
    sub-gap.
  - One substitution hop per round costs O(chain length x module size).
  - `tests/ir_opt_corpus.rs` pins a floor, not the skip count (8), so a
    new example that skips silently still passes.
  - The spec's algorithm step 4 still describes in-call chain resolution;
    the 2026-09-27 log records the one-hop Decision.
- Rulings on points the reviewer declined to judge:
  - An output port aliasing an input or `Const` net does not survive a
    `print_line` -> `parse_line` round trip (port lines carry only a
    width). Predates this pass (`o = a` already does it); the pass makes it
    more common. Stands until IR text needs to round-trip optimized
    modules.
  - Extern output pins not named `out`/`q`/`rdata` would be rewritten as
    readers. Unreachable: extern designs fail `validate`, the pass's
    precondition.
  - Muxes wider than 128 bits: the pass never executes cells, and
    `net_consts` handles wide constants. No issue.
