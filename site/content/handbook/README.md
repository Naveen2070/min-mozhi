# Handbook

The reference you keep open in a second tab while writing Min-Mozhi.

Everything here is Min-Mozhi-specific and checked against the compiler — the
keyword tables are generated from `lang/keywords.toml` at build time, so they
cannot drift from what the compiler actually accepts.

## What this is not

- **Not a tutorial.** If you are starting out, read [Learn](/learn) or the
  [Guide](/guide) first. This section assumes you already know what a module is.
- **Not the normative text.** Where this page and the [Spec](/spec) disagree, the
  spec wins and this page is a bug.

## How to use it

Look things up. Search (top right) covers every page here, including all keyword
spellings — searching a Tanglish or Tamil keyword will find its entry.

> they land.
