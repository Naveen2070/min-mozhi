# Lab

Short exercises, run in your browser. Each step asks you to change one thing in
a real module, and the real compiler — the same WebAssembly build behind the
[Playground](/playground) — decides whether it is right. No install, no
account, nothing leaves your machine.

The lab is where you _do_ it; [Learn](/learn) is where it is _explained_. Every
step links to the chapter that owns its concept, and never re-teaches it at
length. If a step needs more than a few sentences, that material belongs in
Learn, not here.
